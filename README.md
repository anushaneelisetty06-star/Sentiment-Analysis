# Sentiment-Analysis
Amazon Product Reviews Sentiment Analysis project . This project uses Natural Language Processing &amp; Machine Learning techniques to classify customer reviews as Positive, Neutral, or Negative. Implemented text preprocessing, TF-IDF vectorization, model training, evaluation, sentiment prediction using Python and Scikit-learn.
# Amazon Product Reviews Sentiment Analysis
This project was developed during my internship at Pinnacle Labs. It focuses on analyzing Amazon product reviews and classifying customer sentiments as Positive, Neutral, or Negative using Natural Language Processing (NLP) and Machine Learning techniques.

## Project Objectives
* Analyze customer review data
* Perform text preprocessing and cleaning
* Extract features using TF-IDF Vectorization
* Build and evaluate sentiment classification models
* Predict sentiment for new customer reviews

## Technologies Used
* Python
* Pandas
* NumPy
* NLTK
* Scikit-learn
* Matplotlib
* Seaborn

## Machine Learning Models
* Logistic Regression
* Multinomial Naive Bayes
* Random Forest Classifier
## Workflow
1. Data Collection and Loading
2. Data Cleaning and Preprocessing
3. Sentiment Label Creation
4. Text Vectorization using TF-IDF
5. Model Training and Evaluation
6. Model Comparison
7. Sentiment Prediction

## Results
Successfully developed a sentiment analysis system capable of classifying Amazon product reviews into Positive, Neutral, and Negative sentiments. The project demonstrates the practical application of NLP and Machine Learning techniques for text classification.
